# MyYoda v0.7.6 更新

## 新功能

### 社区市场增强 — 版本号 / 下载量 / 分类筛选 / 外部收录

Skill 社区市场全面增强：Skill 卡片展示**版本号与下载量**，新增**分类筛选**，并支持展示**外部收录**的 Skill，找 Skill 更快更准。

### 工作区记忆保留时间语境

工作区记忆（Yoda 记忆）写入规则升级：时间敏感、会随状态更新或具有后续判断价值的阶段性进展，现在会在记忆正文相邻位置**标注事实 / 状态的发生、生效或截至时间**（至少到日期），不再依赖文件修改时间推断；稳定不变的事实无需额外时间戳。

### Yoda 全屏视图收起侧栏后可随时返回

Yoda 插件 / 记忆 / 知识库 / 画布 / 浏览器等全屏视图下收起侧边栏后，**顶部原 TabBar 位置会出现「展开侧边栏」入口**（与普通视图收起态的展开按钮一致，含 ⌘B / Ctrl+B 快捷键），不会再出现收起后无法返回其他页面的情况。

## 修复

- **灵动岛隐藏委托会话**：委托（delegate）会话不再出现在未读完成标记与灵动岛中，避免主会话工作流被误扰。
- **社区市场本地下载计数持久化**：无远端统计端点时，本地下载计数也会正常记录并生效。
- **@ 提及建议修复**：TipTap 异步启动时 `onStart` 不再误拒未登记数组，`@` 提及建议可正常弹出。
- **Windows Tab 栏操作区位置修复**：打开文件面板按钮由"溢出到 TabBar 下方"改为**放回 TabBar 内并精确避让窗口控制按钮区域**（#1537），Windows 下标签滚动区与操作区不再错位。

>
> > "MyYoda" is damaged and can't be opened.
>
> **这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
