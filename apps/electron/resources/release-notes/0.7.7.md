# MyYoda v0.7.7 测试版更新

> **测试版说明**：本版本为 **debug（测试）分支**产物，包含 PR 工作流恢复功能，供实际客户端验证；测试通过后将在正式版分支发布。

## 新功能（恢复）

### Pull Request 完整闭环（恢复 + 修复）

恢复 v0.7.4 引入的 PR 工作流（v0.7.5 因稳定性问题曾回退），本次恢复的同时**修复了导致回退的三个问题**：

- **创建 / 查看 / 合并 / 评论**：可直接在应用内完成 PR 全流程（依赖本机 `gh` CLI，需先安装并登录：`brew install gh` / 官方安装包，然后 `gh auth login`）
- **独立 Tab**：PR 详情在独立 Tab 中打开，支持状态筛选（open / merged / closed）、搜索与参与度筛选
- **左栏 Pull Requests 列表**：左侧栏新增 Pull Requests 模块，列出当前工作区各 Project 的 open PR

### 修复的回退问题

1. **PR 列表恒为空**：仓库候选取值改为各 Project 的 `workingDirectory`（真实 git 仓库路径），不再误用 Agent 工作区内部配置目录
2. **gh 状态检测反复阻塞网络**：`getGhCliStatus` 增加缓存（TTL），不再每次调用同步阻塞 4 次子进程/网络请求
3. **新建 PR 后 number 提取失败**：`gh pr create` 输出 URL 的 PR 编号解析改用 `/\/pull\/(\d+)/`，详情 Tab 不再报错

### 附带

- PR 全屏视图纳入侧边栏收起展开入口：PR 页面收起侧栏后，顶部仍可随时展开返回

>
> > "MyYoda" is damaged and can't be opened.
>
> **这不是安装包损坏。** 安装到 Applications 后执行：

```bash
xattr -cr /Applications/MyYoda.app
open /Applications/MyYoda.app
```
