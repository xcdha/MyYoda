### 回退原因（代码 Bug，非安全漏洞）
1. **PR 列表恒为空**：`PullRequestsView` 用 `getWorkspaceRootPath`（Agent 工作区内部配置目录，非 git 仓库）当 repoPaths，`findGitRoot` 找不到根。应改用 `serverKanbanProjectsAtom` 里各 Project 的 `workingDirectory`（真实 git 仓库路径）。
2. **gh 状态检测反复阻塞网络**：`getGhCliStatus()` 每次同步阻塞 4 次子进程（含 2 次真实网络请求 gh auth status / gh api user），且 6 个入口各自调用。需缓存/去重/异步化。
3. **新建 PR number 提取失败**：`gh pr create` 输出 `.../pull/123`，旧正则 `/#(\d+)\s*$/` 不匹配 → number=0 → 详情 Tab `gh pr view 0` 报错。应改用 `/\/pull\/(\d+)/`。
4. 依赖本机 `gh` CLI（环境门槛高）；PR 工作流的主要业务场景（Skill 社区市场上传）同批被撤。
